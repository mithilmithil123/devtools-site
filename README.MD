# DevTools — DocuMate & FlashForge

Free, open source developer tools. Build with the community.

## 📦 What's Included

- **DocuMate** ⚡ — AI-powered code documentation generator
- **FlashForge** 🔥 — Bootable USB creator for Linux, Windows, and macOS
- **Full-stack web application** with contact form, user signup, and privacy policy

## 🚀 Quick Start

### Prerequisites

- **Node.js** (v14+) - [Download](https://nodejs.org/)
- **Ollama** (for local AI) - [Download](https://ollama.ai/)
- **npm** (comes with Node.js)

### Installation

1. **Clone or download this repo**
```bash
   git clone https://github.com/yourusername/devtools.git
   cd devtools
```

2. **Install dependencies**
```bash
   npm install
```

3. **Start Ollama** (in a new terminal)
```bash
   ollama serve
```

4. **Download a model** (in another terminal)
```bash
   ollama pull mistral
```

5. **Start the backend server**
```bash
   npm start
```

6. **Open in browser**
